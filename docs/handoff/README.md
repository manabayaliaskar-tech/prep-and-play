# Переезд: что здесь лежит

Эта папка — всё, что было вне репозитория в рабочей папке сессии, и что нужно, чтобы продолжить работу.
Скриншоты и кэш не включены (они только весят); если что-то понадобится глазами — пересними.

- `scripts/` — рабочие скрипты:
  - `addkeys.py`, `k_*.py` — добавление ключей переводов в `src/i18n/strings.js` (формат: `K = {'key': ['ru','en','kk']}`);
  - `anim-math-build.mjs` + `anim-math-parts/` — сборка `src/explain/scenes-math.js` из частей. Если править файл вручную, НЕ запускать сборку (перезатрёт правки);
  - `anim-sci-build.mjs` + `anim-sci-parts/` — то же для `scenes-science.js`;
  - `gzserve.mjs` — локальный сервер для проверок (`node gzserve.mjs <папка> <порт>`);
  - остальные `*.cjs`/`*.mjs` — Playwright-проверки экранов и генераторы проверок (запуск из корня проекта, порт в аргументе).
- `content/` — заметки и тексты уроков по языкам (`ja-lessons.txt`, `ko-lessons.txt`, `les*.txt`), `de-tr/`, `ja-ko/` — тексты и выборки для проверки языков, `cur_old.md` — старая карта программы, `ielts_add.txt` — заготовки IELTS.
- `neuroagents/`, `omniroute-serve.log`, `pets/`, `outfits/`, `grades/`, `explain/`, `friends/`, `extra/` — подпапки с файлами сессии (в основном проверочные выгрузки; используйте по необходимости).

Если нужен конкретный скрипт, которого здесь нет — проверь `git log` и `docs/HANDOFF.md`.
