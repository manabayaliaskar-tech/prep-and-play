# Карта программы Prep&Play

Полный список тем по официальным программам (Казахстан и Россия для школы, CEFR для языков,
олимпиадные программы) и что из этого уже есть на сайте. По этой карте пишутся недостающие темы:
у каждой темы - урок (правило, пример, «проверь себя»), генератор на 60+ заданий, шпаргалка.

Обозначения: ✅ есть отдельная тема · 🟡 частично (входит в общую тему, нужна своя) · ❌ нет.

## Итог

| Предмет | Тем в программе | ✅ есть | 🟡 частично | ❌ нет |
|---|---|---|---|---|
| Математика 1-11 и после школы | 171 | 100 | 15 | 56 |
| Английский A1-C2 | 170 | 0 | 43 | 127 |
| Олимпиадная математика | 72 | 12 | 7 | 53 |
| Физика 7-11 | 54 | 0 | 21 | 33 |
| Химия 8-11 | 52 | 0 | 16 | 36 |
| Биология 5-11 | 55 | 0 | 22 | 33 |
| **Всего** | **574** | **112** | **124** | **338** |

Сейчас на сайте 14 общих тем по английскому, 110 по математике (из них 73 - отдельные темы 1-6 классов), 12 по олимпиаде, по 5-9 по наукам:
одна тема вроде «Времена» или «Степени и корни» покрывает то, что в школе занимает 5-10 отдельных тем.
