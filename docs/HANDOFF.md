# Передача проекта (handoff)

Документ для следующей сессии Claude, которая продолжит работу над Prep&Play. Здесь всё, что не записано в README и ROADMAP: незавершённые задачи, договорённости, инструменты, хрупкие места.

## 1. Незавершённое

Всё, что начато, но не опубликовано полностью. Перед работой проверь `git status` и `npm test`.

- **Русский как иностранный (ТРКИ) и итальянский (CILS).** Курсы `rki` и `italian`, экзамены `trki` и `cils`. Частично в коммитах. Нужно: банк грамматики, темы, уроки, PATH_GOAL, карточки, озвучка, флаги (`src/catalog/countries.js`).
- **Математика 7-11 классов и после школы** (около 75 тем, `MATH_BEYOND`). Частично в `src/pools/math/grade7.js` и `hkit.js`. Нужно: 8-11 классы, после школы, уроки, места в курсе, обновить `docs/curriculum.md`.
- **Английский по программе CEFR** (около 150 тем вместо 14 общих). Частично в `src/pools/english/syl/`. Нужно: все уровни A1-C2, `levels.js`, уроки, `docs/curriculum.md`.
- **Аудирование, чтение и письмо** для JLPT и TOPIK: помечены «скоро» на страницах экзаменов. Не сделано.
- **Анимации:** «Задание» в `circle-area` и `volume` не сделано. Подсказки для порядка операций и подобия треугольников не сделаны.
- **GoatCounter** (статистика): ждёт код сайта от пользователя.
- **SQL рейтинга друзей:** файл `supabase/friends.sql`, пользователь должен запустить его в Supabase SQL Editor.

- Пишет по-русски, неформально, с сокращениями. Часто присылает скриншоты с телефона и компьютера. Проверяет всё на iPad, iPhone и ноутбуке.
- Не программист: просит объяснять простыми словами и по шагам (Porkbun, Supabase, GitHub Pages). Код сам не пишет.
- Хочет, чтобы работа делалась самим Claude, а не давались инструкции. Просит максимальное качество, но торопит, не любит лишних вопросов.
- Экономит токены, но разрешает помощников для больших задач. Просит не забывать ни один пункт плана.
- Не записывать в чат пароли и ключи: только через формы сервисов.
- Личные данные (почта, Porkbun, реквизиты, имя) во внешние запросы не отправлять.

Цель проекта: сайт-игра «Prep&Play» для подготовки к экзаменам (ЕНТ, НИШ, БИЛ, ЕГЭ, ОГЭ, SAT, IELTS, TOEFL, HSK, JLPT, TOPIK, Goethe и др.). Доход через подписку: тарифы $2,99 / $3,99 / $4,99 в месяц, скидки 10/20/30% за 3/6/12 месяцев. Пользователь из Казахстана (Астана), ИП планируется после первых оплат.

## 4. Инструменты

- **Репозиторий:** GitHub `manabayaliaskar-tech/School`, ветка `claude/relaxed-maxwell-j0n510`. Автодеплой через CI: тесты → сборка → GitHub Pages. PR не создавать без запроса.
- **Домен:** `prepplay.app` на Porkbun. DNS: A-записи на GitHub Pages, CNAME `www`, TXT для Google, Яндекса и Resend, пересылка `support@prepplay.app` на Gmail пользователя.
- **Supabase:** вход по коду на почту (email OTP), синхронизация прогресса (`progress`), отчёты об ошибках (`reports`), друзья (`board`, SQL не запущен), удаление аккаунта (`delete_me`). Публичный ключ лежит в `src/core/cloud.js` (он публичный по дизайну). Ключ `service_role` и пароль БД в проекте не используются.
- **Resend:** SMTP для писем входа. Домен подтверждён, отправитель `noreply@prepplay.app`. API-ключ хранится только в настройках Supabase SMTP.
- **Поиск:** Google Search Console подтверждён, карта сайта принята, индексация идёт. Яндекс.Вебмастер подтверждён, карта сайта в очереди (инструмент временно только для чтения).
- **Статистика:** GoatCounter, не подключён.
- **Сборка:** esbuild с разбиением на части, статические страницы для поиска (613 страниц на трёх языках, `tools/seo.mjs`), sitemap, robots.
- **Озвучка:** Web Speech API браузера, без сервера. Английский: британский или американский голос по выбору пользователя.
- **Тесты:** `npm test`, 148 тестов: переводы, контент, вёрстка, эмодзи, длинные тире, сверка сгенерированных файлов (`topic-names.js`, `english/levels.js`).
- **Скрипты вне репозитория:** помощник для ключей переводов `addkeys.py` и папка для скриншотов лежат в temp-папке сессии, в репозиторий не входят.

## 5. Договорённости

- **Тире:** только обычный дефис «-». Никаких «—» и «–» ни в тексте, ни в коде, ни в коммитах. В тестах записывать как `—`.
- **Коммиты:** только при зелёных тестах. Пушить только в ветку `claude/relaxed-maxwell-j0n510`. Коммит заканчивается строками `Co-Authored-By` и `Claude-Session`.
- **Модели:** не писать название модели в коммитах, PR, коде и документации.
- **Помощники:** запускать только с согласия пользователя, работать волнами по 3-4 штуки из-за 5-часового лимита. Перед публикацией проверять результат тестами и скриншотами.
- **Языки и экзамены:** экзамен добавляется в `src/catalog/courses.js` и обязательно получает страну в `src/catalog/countries.js` и флаг (SVG, не эмодзи: флаги-эмодзи не работают на Windows).
- **Анимации:** режимы через `hidden` и `btnHidden`, задания через кнопку «Задание». Подпись ползунка получает состояние сцены (`show(value, st)`).
- **Экономика:** Kaspi Pay (0,95%) для Казахстана, для зарубежных карт местный эквайринг без фиксированной платы. Paddle и Lemon Squeezy не нужны (фиксированные $0,50). ВОСМС для ИП около 5 950 ₸ в месяц, уточнить. Ставка упрощёнки 3% или 4% для Астаны, уточнить у бухгалтера.
- **Пункт 5 плана (полная программа):** карта `docs/curriculum.md`, темы 1-6 классов сделаны, 7-11 и английский в работе.

## 6. Хрупкие места и баги

- **Размер первой загрузки:** ~295 КБ сжатием (был 270). Тексты новых курсов попадают в основной код, нужно вынести в ленивые части.
- **Тест «названия тем»** падает, если добавить тему и не запустить `node tools/gen-topic-names.mjs`. Запускать после каждого добавления тем.
- **Тест «английский: уровни»** может падать при частичном добавлении тем: `src/pools/english/levels.js` нужно пересобрать через `tools/gen-english-levels.mjs`.
- **Тесты при параллельной работе:** падают из-за чужих незавершённых файлов. Проверять изолированно в отдельном worktree.
- **Анимации:** кнопки внутри SVG работают только касанием и мышью, не с клавиатуры. Зум лент времени не запоминается.
- **Сцены без «Задания»:** `circle-area`, `volume`.
- **Даты истории, которые стоит проверить по учебнику:** Аныракай 1729 или 1730, Караханиды 942 или 940, Кимекский каганат и Огузское государство «около». Пирс-стрелка для NOR в логике - предположение.
- **ТРКИ и CILS, турецкий:** правила грамматики проверены не полностью.
- **Яндекс-карта сайта:** инструмент временно только для чтения, добавить позже.
- **Jоинт-безопасность:** Supabase RLS включён на всех таблицах. Не отключать.
