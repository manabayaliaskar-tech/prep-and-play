# Prep&Play — подготовка к SAT в виде игры

**Prep&Play** — веб-игра для подготовки к цифровому SAT. Вместо скучных тестов здесь
карта с островами и боссами, дуэли с друзьями, блиц, выживание и пробный экзамен с прогнозом балла.
Каждое задание разобрано на **английском, русском и казахском**.

🔗 **Живая версия:** https://manabayaliaskar-tech.github.io/School/
📦 **Номинация:** Indie Game / Interactive Media — конкурс «Software & AI Showcase» 2026

---

## Проблема

- Подготовка к SAT стоит дорого: курсы и репетиторы — десятки тысяч тенге в месяц.
- Бесплатные материалы — на английском, а объяснения сложных тем на неродном языке понять трудно.
- Решать сотни однотипных тестов скучно — школьники бросают подготовку.

## Решение

Prep&Play превращает подготовку в игру и объясняет каждую ошибку на понятном языке:
сначала на английском (как на экзамене), а если не понятно — одной кнопкой на русском или казахском.

## Возможности

| Режим | Что это |
| --- | --- |
| 🗺️ **Путь к 1600** | 8 островов = 8 доменов SAT, 32 уровня со звёздами и 8 боссов (у каждого — шкала здоровья) |
| 📝 **Пробный экзамен** | Формат цифрового SAT: 2 модуля, таймер, отметки «вернуться позже», адаптивный второй модуль, прогноз 400–1600 и разбор по доменам |
| 🤺 **Дуэль** | Решаешь 10 заданий и отправляешь ссылку другу — у него те же задания. Без регистрации и сервера |
| 🛡️ **Выживание** | 3 жизни, сложность растёт, рекорд |
| ⚡ **Блиц** | 90 секунд — реши как можно больше |
| 🕵️ **Грамматический детектив** | Найди слово с ошибкой в предложении на время |
| 🎯 **Слабые места** | Игра запоминает, где ты ошибаешься, и тренирует именно эти навыки |
| ☀️ **Задание дня** | 5 заданий, одинаковых для всех игроков в этот день |

**Игровые механики:** опыт и уровни, комбо, серия дней, цель дня, 17 достижений, маскот Препи,
звуки, конфетти, вибрация на телефоне. Карта навыков («паутина») по 8 доменам в профиле.

**Языки:** весь интерфейс переключается RU / EN / KZ в любой момент, даже во время задания.
Задания — на английском, как на настоящем SAT.

## Контент

- **Reading and Writing:** 104 авторских задания по всем 11 навыкам SAT (Words in Context, Text Structure,
  Cross-Text, Central Ideas, Evidence, Quantitative Evidence, Inferences, Boundaries, Form/Structure/Sense,
  Transitions, Rhetorical Synthesis). Тексты — в том числе о Казахстане: Абай, Золотой человек, сайгаки, Туркестан.
- **Math:** 20 генераторов по всем навыкам 4 доменов (Algebra, Advanced Math, Problem-Solving and Data Analysis,
  Geometry and Trigonometry). Задачи создаются бесконечно, у каждой — пошаговое решение на трёх языках.
  ~30% заданий с вводом ответа (дроби и десятичные проверяются по правилам SAT).
- **Справочник формул** и ссылка на калькулятор Desmos — как на экзамене.

Все задания авторские, составлены по открытой спецификации College Board. Официальные задания
не копируются. На сайте есть ссылки на официальные бесплатные материалы (Bluebook, SAT Question Bank, Khan Academy).
SAT® — товарный знак College Board; проект с ним не связан.

## Бизнес-модель: freemium

- **Базовый доступ** — карта, все игровые режимы, мини-пробники и разбор каждого задания на трёх языках.
- **Premium (в разработке)** — полные пробники без ограничений, подробная аналитика, план подготовки к дате
  экзамена, ИИ-репетитор и рейтинг класса с кабинетом учителя.
- Пока идёт бета-версия, все функции открыты для всех. Страница тарифов — `#/premium`.

## Технологии и архитектура

- **Чистый JavaScript (ES-модули), HTML, CSS.** Без фреймворков и сборки: сайт открывается мгновенно и работает на слабых телефонах.
- **Разделение ответственности:**
  - `src/content/` — контент (банк заданий, генераторы математики, достижения) — ничего не знает об интерфейсе;
  - `src/engine/` — игровая логика без интерфейса (проверка ответов, опыт/комбо/жизни/босс, прогноз балла);
  - `src/core/` — общие механизмы (маршрутизация, переводы, профиль, звуки, генератор случайных чисел с зерном);
  - `src/ui/` и `src/screens/` — интерфейс.
- **Детерминированная генерация:** одно и то же «зерно» даёт одни и те же задания. На этом построены дуэли
  (без сервера!) и задание дня.
- **21 автоматический тест** (`node:test`): корректность всех 20 генераторов на тысячах вариантов, целостность банка,
  правила ввода ответов SAT, прогноз балла, код дуэли, полнота переводов на 3 языка.
- **CI/CD:** GitHub Actions на каждый коммит запускает тесты и публикует сайт на GitHub Pages.
- Адаптивный дизайн (телефон — нижнее меню как в приложении), управление с клавиатуры (1–4 / A–D, Enter),
  учёт настройки «уменьшить движение». Прогресс хранится в браузере, регистрация не нужна.

## Запуск

**Просто открыть:** https://manabayaliaskar-tech.github.io/School/

**Локально** (нужен [Node.js](https://nodejs.org) 22+):

```bash
git clone https://github.com/manabayaliaskar-tech/School.git
cd School
npm start      # сайт на http://localhost:3000
npm test       # тесты
```

Без Node.js: `python3 -m http.server` в папке проекта → http://localhost:8000
