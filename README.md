# AlgoVision — увидеть алгоритм, значит понять его

**AlgoVision** — интерактивный веб-тренажёр по алгоритмам для школьников и студентов.
Алгоритмы показаны пошаговой анимацией, и каждый шаг объясняется на русском языке.
Работает прямо в браузере, на компьютере и телефоне, без регистрации и установки.

🔗 **Живая версия:** https://manabayaliaskar-tech.github.io/School/
📦 **Номинация:** Indie Game / Interactive Media — конкурс «Software & AI Showcase» 2026

## Какую проблему решаем

Алгоритмы — одна из самых сложных тем школьной информатики и олимпиад. В учебнике
сортировка — это пять строк кода и картинка, а понять, *что происходит на каждом шаге*,
трудно. Существующие визуализаторы в основном на английском, без пояснений и без
проверки понимания.

AlgoVision:

- **показывает** каждый шаг алгоритма и **объясняет** его простыми словами;
- **проверяет понимание**: в игре «Угадай шаг» алгоритм останавливается и спрашивает, что будет дальше;
- **сравнивает** алгоритмы наглядно: в «Гонке» пять сортировок соревнуются на одном массиве;
- работает **на телефоне**, бесплатно и без установки.

**Целевая аудитория:** ученики 7–11 классов, участники олимпиад, учителя информатики
(для показа на уроке на проекторе), первокурсники IT-специальностей.

## Возможности

| Раздел | Что умеет |
| --- | --- |
| **Сортировки** | 5 алгоритмов: пузырьком, выбором, вставками, слиянием, быстрая. Пошаговое воспроизведение вперёд и назад, перемотка, скорость, подсветка строки псевдокода, счётчики сравнений, обменов и записей, оценки сложности. Можно ввести свой массив. |
| **Игра «Угадай шаг»** | Перед каждым сравнением вопрос «Поменяются ли местами 66 и 90?». Счёт, серия, рекорд. |
| **Гонка** | Все сортировки одновременно на одном массиве, медали и вывод о том, почему победил именно этот алгоритм. Типы данных: случайные, почти отсортированные, обратные, с повторами. |
| **Поиск пути** | BFS, DFS, Дейкстра, A*. Рисование стен и «болота» мышкой или пальцем, перетаскивание старта и финиша, генератор лабиринтов, мгновенный пересчёт пути при изменении поля, таблица сравнения алгоритмов. |
| **Квиз** | 10 случайных вопросов из банка с разбором каждого ответа и рекордом. |

## Технологии и архитектура

- **Чистый JavaScript (ES-модули), HTML и CSS.** Без фреймворков и без сборки, поэтому сайт мгновенно открывается и работает даже на слабых компьютерах.
- **Логика алгоритмов отделена от интерфейса.** Алгоритм ничего не рисует: он только записывает шаги, а интерфейс их проигрывает. Поэтому каждый алгоритм можно протестировать отдельно.
- **Свои структуры данных:** двоичная куча (приоритетная очередь) для Дейкстры и A*, генератор случайных чисел с зерном для воспроизводимых тестов.
- **51 автоматический тест** (встроенный `node:test`): корректность сортировок на сотнях случайных массивов, совпадение стоимости пути у A* и Дейкстры, связность лабиринтов и т. д.
- **CI/CD:** GitHub Actions на каждый коммит запускает тесты и, если они прошли, автоматически публикует сайт на GitHub Pages.
- Адаптивная вёрстка (телефон, планшет, компьютер), управление с клавиатуры, учёт настройки «уменьшить движение».

```
index.html               — разметка страницы
styles/main.css          — дизайн
src/
  main.js                — переключение разделов
  core/                  — общие механизмы
    player.js            — «плеер» шагов (старт, пауза, шаг, перемотка)
    heap.js              — приоритетная очередь
    random.js            — генератор случайных чисел с зерном
    storage.js           — сохранение рекордов
  algorithms/            — чистая логика, без интерфейса
    sort-recorder.js     — запись шагов сортировки
    sorting.js           — 5 сортировок + псевдокод и сложность
    pathfinding.js       — BFS, DFS, Дейкстра, A*
    maze.js              — генератор лабиринтов
    arrays.js            — генерация и разбор массивов
  data/quiz-questions.js — банк вопросов квиза
  ui/                    — интерфейс каждого раздела
tests/                   — автоматические тесты
docs/                    — материалы для конкурса
```

## Как запустить

**Вариант 1 — просто открыть ссылку:** https://manabayaliaskar-tech.github.io/School/

**Вариант 2 — локально** (нужен [Node.js](https://nodejs.org) 20+):

```bash
git clone https://github.com/manabayaliaskar-tech/School.git
cd School
npm start        # сайт откроется на http://localhost:3000
npm test         # запустить тесты
```

Без Node.js можно так: `python3 -m http.server` в папке проекта, затем открыть http://localhost:8000.

## Управление

- <kbd>Пробел</kbd> — старт/пауза, <kbd>←</kbd> <kbd>→</kbd> — шаг назад/вперёд;
- в квизе <kbd>1</kbd>–<kbd>4</kbd> — выбрать ответ.
